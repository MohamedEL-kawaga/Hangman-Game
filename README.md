# Hangman Game

## Overview

Hangman Game is a responsive web-based word guessing game built using HTML, CSS, and JavaScript. Players must guess the hidden word by selecting letters from the alphabet. Each incorrect guess gradually draws the hangman figure. The game ends when the player successfully guesses the word or reaches the maximum number of wrong attempts.

## Features

- Random word generation from multiple categories.
- Dynamic alphabet keyboard generation.
- Real-time letter validation.
- Progressive hangman drawing for incorrect guesses.
- Win and Game Over popups.
- Sound effects for correct and incorrect answers.
- Responsive design for mobile, tablet, and desktop devices.
- Play Again functionality without leaving the page.

## Categories

The game randomly selects a word from one of the following categories:

- Programming Languages
- Movies
- Famous People
- Countries

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)



## How to Play

1. Open the game in your browser.
2. Check the displayed category.
3. Click on letters to guess the hidden word.
4. Correct letters appear in their positions.
5. Wrong guesses draw parts of the hangman.
6. You win if you reveal the entire word before reaching the maximum mistakes.
7. You lose if the hangman is completed.

## Game Logic

- The game randomly selects a category.
- A random word is chosen from that category.
- Alphabet buttons are generated dynamically using JavaScript.
- Correct guesses reveal matching letters.
- Incorrect guesses increase the wrong attempts counter.
- After 8 wrong attempts, the Game Over screen appears.
- If all letters are guessed correctly, the Win screen appears.

## Responsive Design

The project follows a Mobile-First approach and adapts to:
